# Heráclito.IA

Repositorio del equipo **Heráclito.IA** para el desafío Platón (Tertulia).

## Estructura

- `leyes-de-platon.md` — Leyes de Calípolis, normativa común a todos los niveles
- `nivel-1/hallazgos.json` — entrega del nivel 1 (Tres contratos, una ley)
- `nivel-1/enunciado.md` — consigna del nivel 1
- `nivel-1/contratos/` — contratos C-101, C-102 y C-103 analizados
